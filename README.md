# ff

To build project:
1) Configure CMake cache (preferably add shortcuts from .vscode/keybindings.json to your preferences and press Ctrl+Shift+C)
3) Launch build-debug.ps1 or build-release.ps1 (preferably use VSCode and just press Ctrl+Shift+B and choose proper build type)
3) Launch the .exe file built in previous step (preferably  in VSCode press F5 and choose the build type)
